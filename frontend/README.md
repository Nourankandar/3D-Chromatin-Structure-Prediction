# ملفات تجريبية للعارض (مريض + سليم)

بيانات مبنية على منطقة حقيقية من chr21 (14.20M–15.48M)، مع تشويه موضعي
بالمريض بمنطقة (نقاط 69–110) يقلّد أثر طفرة على انطواء الكروماتين.

## الملفات

| الملف | الاستخدام |
|---|---|
| `dual_patient_control.json` | **المدمج** — يعرض المريض + السليم فوق بعض (split screen) بضغطة وحدة |
| `patient_only.json` | المريض لحاله |
| `control_only.json` | السليم لحاله |

## كيف تجرّبي

1. افتحي `hic_viewer.html` بالمتصفح
2. اضغطي زر **📂 استيراد**
3. اختاري **`dual_patient_control.json`**
4. رح يظهر الخيطين: المريض (أخضر) + السليم (رمادي فاتح) فوق بعض
5. زر **◑ السليم** بالـ toolbar لإظهار/إخفاء طبقة السليم

## الفرق المتوقّع
- **السليم**: بنية منتظمة (stress أقل)
- **المريض**: منطقة مفكوكة الالتواء بالثلث الأول (stress أعلى) — تبيّن أثر "الطفرة"
